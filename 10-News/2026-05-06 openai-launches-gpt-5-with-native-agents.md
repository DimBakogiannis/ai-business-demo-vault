# OpenAI Launches GPT-5 With Native Agentic Tools

> [!summary] TL;DR
> [[OpenAI]] released [[GPT]]-5 today, the first model in the [[ChatGPT]] family with built-in tool use, persistent memory, and a substantially larger context window. [[Microsoft]] confirmed same-day rollout to Azure customers.

## Key Concepts
[[OpenAI]], [[GPT]], [[ChatGPT]], [[Large Language Models]], [[AI Agents]], [[Agentic AI]], [[Microsoft]], [[Reasoning Models]]

## Summary
GPT-5 ships with what OpenAI calls "native agency" — the model decides on its own when to invoke tools, when to reason in long form, and when to call back to the user for clarification, without an external orchestration layer. Benchmarks released alongside the launch show GPT-5 leading on SWE-Bench Verified, GPQA Diamond, and MMLU-Pro. Pricing is unchanged from the GPT-4.1 family.

The release positions [[OpenAI]] aggressively against [[Anthropic]]'s [[Claude]] and Google's [[Gemini]] in the [[Reasoning Models]] tier.

## Why It Matters
Native tool use removes the most common failure mode in [[AI Agents]] today — brittle scaffolding around prompt-glued tool calls. For [[Enterprise AI]] teams, this collapses an entire category of workflow code into a single API call. Expect knock-on effects across the agent framework ecosystem.
